# beatsleep.web

The public site for **BeatSleep** — the privacy policy, the support page and the
terms of use that the App Store listing points at.

Static HTML, no build step, no JavaScript, no analytics. The palette and the
type are the app's own: black ground, nothing above 90% white, accent at OKLCH
hue 282.

```
index.html      what the app is           /es/index.html
privacy.html    privacy policy            /es/privacy.html
support.html    support and FAQ           /es/support.html
terms.html      terms of use              /es/terms.html
```

Served by GitHub Pages from `main`. Editing a file and pushing publishes it.
